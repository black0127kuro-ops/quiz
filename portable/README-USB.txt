USB quiz-lan-usb folder

1. Copy this entire folder to USB
2. On school PC, double-click quiz-lan.bat (no Node install)
3. If Windows Firewall asks: allow on PRIVATE network (required for participants)
4. Open http://localhost:3000 on that PC
5. Tell participants http://(IPv4 shown):3000 and room code

If you clicked Block by mistake:
  - Run allow-firewall-once.bat as Administrator (once), OR
  - Settings - Firewall - Allow an app - allow node.exe on private network

Participants need browser only.
