使い方ガイド

授業の確認や通常の早押しクイズなどに使える、個人で作成した無料の早押しクイズサイトです。 主催者が問題を出し、参加者が「押」ボタンで早押しして口頭で答えます。 このページを最初に読めば、初めての方でも進行できます。

クイズの流れ（全体像）

  1. 主催者が部屋をつくる → 4桁の部屋番号が表示される
  2. 参加者がその番号とニックネームを入れて入室する
  3. 主催者が問題を選び「この問題で出題」 → 画面上に問題文が1文字ずつ流れる
  4. 参加者が「押」（またはスペースキー）で早押し → 出題が止まり、早押し順が決まる
  5. 早押しした人から10秒以内に口頭で回答 → 主催者が正解 / 不正解を押す
  6. 不正解なら次の早押し順の人へ。全員不正解または正解でその問は終了 → 解説が出る
  7. 次の問題へ進む。最後に結果発表で順位を表示できる

正解メモ・解説は出題中には見えません。正解・不正解のあと、全員の画面に表示されます。

始める前の準備

  • 主催者用 … パソコン＋大きめの画面（プロジェクター推奨）＋このサイトの主催者画面
  • 参加者用 … スマホまたはパソコン＋「参加者」画面（Chrome など最新ブラウザ推奨）
  • 同じ Wi‑Fi / ネット … みんなが同じサイトの URL にアクセスできること
  • 部屋番号 … 主催者から伝えられた4桁の番号だけで参加します（サイト全体のパスワードはありません）
  • 音声 … 効果音を鳴らす場合、ブラウザで一度画面をタップして「音を許可」してください

トップ画面（部屋の作成・参加）

主催者：部屋をつくる

「部屋をつくる」を押すと、自動で4桁の部屋番号が発行され、主催者画面に移動します。

参加者にこの番号を伝えてください（口頭・チャット・画面に写すなど）。

参加者：参加する

  1. 部屋番号（4桁の数字）を入力
  2. ニックネーム（表示名）を入力
  3. 「参加する」を押す

同じ部屋に、別のニックネームで何人でも参加できます。

主催者の操作

問題の用意

  • 問題リスト … 左側の一覧から問題を選び、問題文・正解メモ・配点・解説を編集
  • ＋ 新規追加 … 問題を増やす
  • 問題セット管理 … まとまった問題をお使いのブラウザに保存・読み込み・エクスポート（サーバーには送信しません）
  • 出題済み … すでに出した問題には印が付きます

出題と進行

操作いつ使うか
この問題で出題選んだ問題を最初から流す（早押し・得点はリセット）
続きを流す早押しで止まったところから、また文字が流れ始める
次の問題へ別の問題に切り替え（早押し順などリセット）
流れる文字の速さ1文字あたりの表示速度（遅い←→速い）
正解 / 不正解回答者の口頭回答を聞いて判定（効果音あり）

キーボードショートカット（主催者）

Space … 出題開始 / 続きを流す / 次の問題へ（状況に応じて自動切替）
O または 1 … 正解
X または 2 … 不正解
N … 次の問題へ
R … 今の問題を最初から
S … 問題順をシャッフル
? … ショートカット一覧

その他の主催者機能

  • 効果音設定 … デデン・正解・不正解・カウントダウンなどを差し替え
  • 結果発表 … 表彰台アニメーションで順位表示
  • スコア表示 ON/OFF … 参加者に自分の得点・順位表を見せるかどうか
  • お助けアイテム … 使う種類にチェック → 問題の合間に手動で配布（下記）

お助けアイテムの配布（主催者）

  1. 「お助けアイテムを使う」にチェックを入れる
  2. 使いたい種類にチェック（第1問が始まったあとは種類の変更不可）
  3. 出題中・回答中以外の合間で「アイテム配布」から配る
  • 配布先ランダム … 参加者の中からランダム
  • 上位3名以外へ … スコア上位3名を除いてランダム
  • 選択者に配布 … プルダウンで指定（アイテムも指定必須）
  • アイテム欄で 🎲 ランダム を選ぶと、有効な種類からランダムで1つ配る

参加者の操作

早押し

  • 画面の大きな「押」ボタン、またはスペースキーで早押し
  • 早押しすると問題文の表示が止まり、早押しランキングに順位が付く（上位5名まで表示）
  • 自分の順番が来たら10秒以内に口頭で回答（主催者が正誤判定）
  • 出題中・自分以外が回答中は押せません

画面の見方

  • 出題エリア … 主催者と同じ問題文が1文字ずつ流れる
  • 早押しランキング … 誰が何位で押したか・回答中の人
  • スコア … 主催者が ON にしているときだけ表示
  • お知らせ … アイテムの配布・使用など（青＝全体、赤＝自分だけ）
  • リアクション … 拍手などのスタンプ（雰囲気づくり用）

お助けアイテム（参加者）

  • 主催者から配布されると「お助けアイテム」欄に表示される
  • タップで使用（多くは次の問題に効果。シールドはすぐ有効）
  • 使ったアイテムは所持から消える
  • 出題中・回答中は使えない
  • ボタンに書いてある効果の説明を読んでから使う

押ボタンのカスタム

「左右入れ替え」でレイアウト変更、デザイン一覧から押ボタンの見た目を選べます（お好みで）。

お助けアイテム一覧

主催者が使う種類にチェックしたものだけがゲームに登場します。 配布は主催者が問題の合間に行います。

よくある質問

参加者が入室できない
部屋番号が4桁か、主催者がまだ部屋を作っているか確認してください。
押しても反応しない
出題が始まっているか、すでに誰かが回答中でないか確認してください。ページを再読み込み（Ctrl+Shift+R）して再度参加も試してください。
音が鳴らない
ブラウザは最初のクリックまで音を鳴らさないことがあります。画面を一度タップしてから、主催者が再度操作してください。
主催者画面を閉じたらどうなる？
部屋は主催者が接続している間だけ有効です。主催者のブラウザを閉じると部屋がなくなるので、進行中は主催者画面を開いたままにしてください。
正解メモは参加者に見える？
出題中は見えません。正解・不正解の判定後に、解説バナーで正解と解説が表示されます。
スマホで主催できる？
可能ですが、問題編集や配布操作はパソコンの方がやりやすいです。進行だけならスマホでもできます。
画像は使える？
いいえ。第三者コンテンツをサーバーに保存しないため、画像の添付・アップロード機能はありません。
問題セットはどこに保存される？
主催者が使っているブラウザの localStorage のみです。別の端末やブラウザでは表示されません。バックアップは「エクスポート」で JSON を保存してください。
